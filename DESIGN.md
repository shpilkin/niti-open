# Niti — Design System

Единый референс для UI. Цель — **не изобретать заново** то, что уже есть.
Перед тем как писать CSS/шаблон, свериться с этим файлом.

- Токены: `static/tokens.css` (подключается перед `app.css`)
- Компоненты: реализованы классами в `static/app.css`
- Живая витрина: открыть `styleguide.html` в браузере

---

## Железные правила

1. **Никаких сырых значений в компонентах.** Ни `#hex`, ни `14px`, ни `999px`
   напрямую. Только `var(--token)`. Нет подходящего токена → добавь его в
   `tokens.css`, потом используй.
2. **Сначала переиспользуй.** Нужна кнопка → `.btn` (+ `.primary`/`.sm`/`.danger`).
   Плашка статуса → `.st-pill`/`.chip.*`. Не плоди пятую вариацию.
3. **Тёмная тема бесплатна.** Если взял семантический токен (`--danger`,
   `--warning-bg` …), тёмная тема уже работает. Хардкод хекса её ломает —
   придётся дублировать в `@media (prefers-color-scheme: dark)`. Не делай так.
4. **Статусные цвета — только семантика.** waiting → `--warning`,
   needreply → `--danger`, commitment → `--success`, delegated → `--delegated`,
   info → `--info`.

## Токены

### Цвет — нейтральные
`--bg` `--sidebar` `--card` `--card-hover` — поверхности
`--text` `--subtle` `--muted` — текст по убыванию контраста
`--border` `--hover` `--active` `--chip` — границы и состояния

### Цвет — акцент (бренд)
`--accent` `--accent-weak` (подложка) `--accent-strong` (hover/press)

### Цвет — семантика статусов
Каждый статус — пара `fg` + `-bg`:
`--success/-bg` · `--warning/-bg` (+`--warning-border`) · `--danger/-bg` ·
`--info/-bg` · `--delegated/-bg`

### Отступы (шаг 4px)
`--sp-1`..`--sp-7` = 4 · 8 · 12 · 16 · 24 · 32 · 48. Для padding/gap/margin.
`--control-h` (34px) — рост поля, выпадающего списка и кнопки, стоящих в одной строке
формы: разная высота читается как «кнопка провалилась в поле».

### Типографика
Размеры: `--fs-xs`(11) `--fs-sm`(12) `--fs-md`(13) `--fs-base`(14)
`--fs-lg`(15) `--fs-xl`(18) `--fs-2xl`(22)
Веса: `--fw-normal/medium/semibold/bold` (400/500/600/700)
Интерлиньяж: `--lh-tight`(1.3) `--lh-normal`(1.5) `--lh-loose`(1.6)

### Строка задачи
`--row-h`(42) — высота `.trow` · `--tools-h`(36) — полоса инструментов и призрачная
строка · `--col-who`(168) — колонка контрагента ·
`--col-end`(124) — правая ячейка (дата или четыре hover-действия по `--act-sm`(26)) ·
`--bar-w`(3) — левая полоса · `--drop-max-h`(260) — высота выпадающего списка

### Календарь
`--cal-hour-h`(44) — высота часа в сетке, сутки = 24 таких · `--cal-gutter`(52) — шкала
часов · `--cal-ev-gap`(2) — зазор вокруг блока события · `--cal-now-w`(2) — линия «сейчас» ·
`--cal-today-d`(26) — кружок сегодняшнего числа · `--cal-mini-cell`(30) — клетка
календарика · `--cal-month-h`(104) — высота дня в месяце.
`--cal-1`…`--cal-6` (+ `-bg`) — цвета календарей ящиков, обе темы. Отдельная палитра, а
не статусы: календарь красного цвета не значит «просрочено».

### Радиусы
`--r-xs`(6) `--r-sm`(10) `--r`(14) `--r-pill`(999)

### Тени / слои / тайминги
`--shadow` `--shadow-pop` · `--z-splitter/toast/menu` · `--t-fast`(.12s) `--t-med`(.4s)

## Инвентарь компонентов

Что уже есть в `app.css`. Классы — как называть, чтобы попасть в стиль.

### Кнопки
- `.btn` — базовая (пилюля, обводка). Модификаторы: `.primary` (акцент-залив),
  `.success` (зелёная-семантика: «пустая» в покое, мягкая заливка на hover/press —
  для позитивного действия, напр. «Готово»), `.sm` (компактная), `.danger` (красная,
  зеркало `.success`), `[disabled]`. Все кнопки имеют press-состояние (`:active` —
  сдвиг + фон) и фокус-кольцо (`:focus-visible`), чтобы клик читался как клик.
- `.btn.icon` — `.btn` с одной иконкой (меню «⋯» в панели).
- `.seg` — сцепленные `.btn`: один контрол на семейство взаимоисключающих действий
  («Ответить | Всем | Переслать»), а не три одинаковые пилюли.
- `.icon-btn` — квадратная иконочная кнопка в шапке.
- `.act` / `.act.ok` — микро-действия на карточке (появляются на hover).
- `.pager-btn` — навигация пагинации.
- `.back-link` — текстовая «назад» акцентом.
- `.ic-spin` — иконка внутри кнопки, крутящаяся, пока htmx ждёт ответ
  (`.htmx-request` вешается на кнопку сам). Уважает `prefers-reduced-motion`.

### Плашки / метки
- `.chip` (+ `.sm`) — квадратная иконка-аватар (внутри — `icon()`). Статусы:
  `.waiting` `.needreply` `.commitment` `.delegated` `.info`. Тип → (иконка, статус)
  берётся из `TYPE_META` (`api/common.py`), подпись — из `TYPE_LABEL`.
- `.badge` — счётчик-пилюля в навигации.
- `.st-pill` (+ `.ok`/`.err`/`.paused`) — статус аккаунта; (+ `.high`/`.medium`/`.low`) —
  важность карточки в совете (степень считает правило `advice.importance`);
  (+ `.mine`/`.remind`/`.wait`/`.idle`/`.flow`) — состояние Нити, свёртка её обязательств
  (`attention.py`, docs/feature-topics.md §8.2): на мне / пора напомнить / жду / затухла
  / идёт. Подпись даёт `ThreadAttention.label`, класс — `.css`.
- `.lbl-chip` (+ `.mini`) — цветной ярлык.
- `.src-tag` / `.badge-type` / `.st` — теги источника/типа. `src-tag` на `<a>` —
  источник, который можно открыть (встреча за задачей).
- `.tag` (+ `.dot`/`.vip`/`.rem`) — мелкая метка у заголовка карточки: правка вручную,
  кандидат на закрытие, VIP-отправитель (`.vip` — звезда `--warning`), «пора напомнить»
  (`.rem` — часы `--warning`: чужой ход молчит дольше порога из Настроек → Общие).
- `.soon-badge` — «скоро».
- `.export-ok` / `.export-err` — итог сохранения рядом с кнопкой формы.

### Контейнеры
- `.proj-state` — строка состояния Нити под описанием на её странице: пилюля `.st-pill`
  плюс счётчики «с даты · бесед · встреч · на мне · чужой ход · движение N дн. назад».
- `.banner.warn.thread-ask` (+ `.acts` с формами) — вопрос затухшей Нити «ещё актуальна?»
  и три ответа §8.4 `docs/feature-topics.md`: «Продолжать» (`.btn.sm.success`), «Отложить до»
  с полем даты, «Снять с досок». Та же плашка — у отложенной Нити.
- `.nav-item .st-pill` — пилюля состояния Нити в сайдбаре, только «на мне» и «затухла».
- `_card_threads.html` — чипы Нитей в панели обязательства (`.proj-chip`): прямая
  привязка с крестиком, унаследованная от беседы/встречи — с галочкой без крестика,
  «Новая нить» — одним кликом; тот же чип в панели письма и встречи.
- `.prompt-card` · `.prov-card` · `.acc-row` · `.msg` (+ `.me`) — вариации карточек.
  Письмо с разметкой карточка показывает в песочнице (`.msg-html` + `.msg-plain`), как
  почтовая панель: плоским текстом таблицы и списки рассыпаются.
- `.banner` (+ `.ok`/`.warn`) — информационная плашка на всю ширину.
- `.reason-box` — блок «почему» акцентом. `.reason-box.advice` (+ `.adv-lead`, `.adv-imp`,
  `.adv-points`, `.adv-risk`) — совет ассистента в панели карточки, ровно четыре строки:
  что сделать и о чём тред, важность с доводом, до трёх действий, цена бездействия;
  грузится после панели на место своей заглушки, `.act` в заголовке пересчитывает; при
  «закрыть как дубль» — `.pane-actions` с одной `.btn.sm.success`.
  `.ev` — чип-улика после утверждения (`<a>` — открывает письмо/карточку/встречу/тред в
  панели, `<span>` — без перехода; `ev_chips(..., limit=N)` показывает N чипов и
  дописывает «ещё k» с остальными подписями в подсказке). Печатает, КАКАЯ это улика («Соколов, 10.09»), вид
  несёт иконка (`Ref.icon`), полная подпись — в `title`. Разметку даёт макрос `ev_chips`
  в `templates/_macros.html` — он один для совета и брифинга, вручную не копировать.
- `.src-block` (+ `.src-line`, `.src-sum`) — источник задачи, у которой нет писем: подпись
  «сказано на встрече …», под ней «о чём» встреча (`.src-sum`) + `.pane-actions` с кнопками
  к встрече и расшифровке.
- `.mt-sum` — сводка встречи по разделам в её панели: «О чём» строкой, «Обсудили /
  Договорились / Открытые вопросы» — подзаголовок `h4` и список (`meetings.summary_blocks`).
- `.tc-hit` — подсветка куска расшифровки, на который сослалась задача.
- `.mono-block` (+ `.sm`, `.block`) — моноширинный блок: код для сверки глазами
  крупно; `.sm` — длинная строка для чтения и копирования (MCP-токен, готовая команда);
  `.block` — многострочный кусок конфигурации, переносы сохраняются.
- `.copy-line` (+ кнопка `.act.copy`, состояние `.copied`) — значение, которое пришли
  скопировать: сам текст и кнопка «два квадрата» справа, по клику кладёт значение в
  буфер и на секунду показывает галочку. Разметку даёт макрос `copy_value` в
  `templates/_macros.html`, обработчик — `ui.js` по `data-copy`. Всё, что человек
  копирует руками (токен, адрес, готовая команда), показывать через него.
- `.field-row` (+ `.field-label`) — подписанное значение в настройках: подпись сверху
  мелким приглушённым, значение под ней.
- `.tr` (+ `.ok`/`.err`) — результат теста подключения.

### Списки
- `.trows` / `.trow` (+ `.overdue`/`.muted`/`.sel`/`.attn`) — строка задачи: одна
  строка на обязательство (иконка типа `.trow-ic.<статус>`, колонка `.trow-who`,
  `.trow-title` + приглушённый `.trow-reason`, иконка источника `.trow-src`, справа
  `.trow-date` (+`.over`/`.today`) либо hover-`.actions` из `.act`). `.tsec` (+ `.tsec-n`
  счётчик) — заголовок секции внутри списка. Разметку даёт макрос `task_row` в
  `templates/_taskrow.html` — не копировать вручную. Карточек `.card` в списках больше
  нет (docs/ux-tasks.md). Две раскладки по ширине списка (container query в `app.css`):
  широкий — одна строка, узкий — заголовок сверху, контрагент + reason снизу.
  `.trow.static` — строка без жизненного цикла (решение, факт): показывается, не
  открывается. `.trow-chk`/`.trow-check` — чекбокс выделения (bulk), `.trow.cur` — курсор клавиатуры
  (`j/k`, `Enter`, `e`, `s`, `#`, `x`, `n` — см. `ui.js`), `.trow.checked` — отмечена.
  `.trow.flash` — короткая подсветка только что добавленной строки. `.trow-lbls` — метки
  беседы тем же чипом `.lbl-chip.mini`, что в почте (правило из «Метки и правила» —
  это «от кого это», и на задаче оно читается так же). Ширину списку задаёт область
  содержимого, а не константа: `#list` тянется за разделителем, длину строки выбирает
  пользователь перетаскиванием.
- `.space-card` (+ `.space-head`, `.space-name`, `.space-sub`, `.bot-form`, `.space-new`) —
  Настройки → Пространства: карточка пространства с именем-инпутом, моделью, ящиками
  (`_accounts.html`) и Telegram-ботами.
- `.pane-bars` — действия панели двумя полосами `.pane-actions` (docs/ux-tasks.md §15):
  жизненный цикл обязательства («Готово», «Отложить ▾», «Срок ▾», «⋯») и почтовые
  действия (черновик ассистента + `.seg`). Одно семейство на роль, один primary на полосу;
  меню — `openContextMenu` из `ui.js`, как у кнопки срока в строке. В панели встречи —
  кнопка пространства (`data-space-menu`, меню «Перенести в …») и `.btn.danger` «Удалить».
- `.tools` (+ `.tools-main`, `.tools-sel`, `.tools-dd`/`.tools-lbl` с `<select>` и `.tools-chev`, `.tools-add`,
  `.tools-count`, `.tools-act`) — липкая полоса инструментов доски высотой `--tools-h`,
  первый ребёнок `#list` (docs/ux-tasks.md §13). Группировка и ящик — выпадающие списки
  без рамки, «+ Задача» справа. При отмеченных строках та же полоса (`.selecting`)
  показывает счётчик и массовые действия — список не сдвигается. В узком списке
  (container query на `#list`) подписи действий прячутся, остаются иконки с `title`.
  Почтовый список пользуется той же полосой (синхронизация и время последнего обмена);
  когда показывать нечего — полосы нет. Действие экрана («Написать» иконкой `compose`)
  живёт в блоке `head_actions` шапки: она не прокручивается вовсе.
- `.qadd` (+ `.qadd-ic`, `.qadd-input`, `.qadd-due` (+`.set`, `.qadd-due-lbl`), `.qadd-key`) —
  быстрое добавление задачи призрачной строкой под полосой (`_quickadd.html`): без рамки,
  высота `--tools-h`; на «Сегодня» и «Мои задачи» видна всегда, на других досках — по
  «+ Задача» или `n`. `.qadd-due` — срок будущей задачи тем же меню дат, что у строки:
  молчит, пока срока нет, и называет его (`.set`), когда есть. Полоса липкая
  (`top: var(--tools-h)`, сразу под `.tools`): подсветка добавленной строки уводит длинный
  список вниз, и поле ввода уезжало с экрана.
- `.mlist` / `.mrow` (+ `.sel`/`.unread`/`.muted`/`.attn`/`.sub`/`.expanded`) — почтовый
  список (стиль macOS Mail). Разметку строки даёт макрос `mail_row` в
  `templates/_mailrow.html` — не копировать вручную: та же строка рисуется в списке и
  внутри раскрытой беседы. `.mrow-exp` — стрелка раскрытия беседы, `.mrow-kids` —
  контейнер её писем (грузятся раз, дальше прячутся). При включённой группировке по теме
  (Настройки → Общие) строка одна на переписку, размер переписки — `.tag` рядом с темой.
- `.srows` / `.srow` (+ `.sel`/`.cur`/`.static`) — строка результата поиска, одна форма
  для всех видов (письмо, обязательство, встреча, момент встречи, событие, человек,
  проект): чип вида слева, `.srow-title` с `<mark>` на совпавших словах, `.srow-who`,
  `.srow-date`, `.srow-snip`. У письма в `.srow-date` ещё и час, а вложение помечено
  скрепкой — тем же `.mrow-clip`, что в строке почты. Разметку даёт макрос `result_row` в
  `templates/_searchrow.html`; `.static` — строка без перехода (событие календаря).
  `.search-chips` — полоса `.proj-chip` над результатами: каждый чип дописывает или
  снимает оператор в строке запроса.
- `.prow` (+ `.prow-body`, `.prow-chk`, `.prow-ids`) — строка человека на экране «Люди»:
  `.mrow` с чекбоксом выбора слева и полосой чипов под именем (docs/feature-people.md §4).
- `.idchip` (+ `.name`, `.src`, `.open`, `.warn`) — чип личности человека: адрес, второе
  имя, источник, число открытых обязательств. Внутри может быть `.chip-x` — отвязать.
- `.tools-search` — поле поиска в липкой полосе (экран «Люди»).
  `.trow` — его родственник: те же разделители-линии, левая полоса и состояния.

### Формы
- `.inline-form` — строка «поле + список + кнопка» в настройках (метки, правила): всё
  ростом `--control-h`, разрыв `--sp-2`.
- `.compose-form` · `.wz-form` · `.edit` — формы. Инпуты внутри наследуют стиль
  (обводка `--border`, фокус → `--accent`). В `.pane-inner.compose` форма тянется на
  всю высоту панели, а поле текста (`.field-body`) забирает весь остаток — кнопки и
  поля остаются видны; на низком окне панель скроллится, текст не ниже min-height.
- `.edit` понимает и `textarea` (заметки о человеке в панели «Память»).
- `.hist` (+ `.hist-list`, `.hist-row` с ролями `.auto` / `.user` / `.drop`, `.hist-when`,
  `.hist-what`) — история карточки в панели: тот же тихий `details`, что «Исправить», но
  её читают, а не заполняют (docs/ux-tasks.md §17). Отдельное имя нужно и потому, что
  меню «⋯» открывает первый `details.edit` в панели. Роль `.drop` приглушена: снятие
  карточки с доски не должно читаться как исполненное обязательство.

### Настройки → Доски
- `.board-list` / `.board-row` (+ `.off` для скрытой) / `.board-form` / `.board-head` /
  `.board-body` / `.board-ic` / `.board-name` / `.board-sel` / `.board-chk` /
  `.board-types` / `.board-opts` / `.board-note` / `.board-acts` — карточка доски в
  настройках (docs/ux-tasks.md §17.5): имя и видимость в шапке, типы и порядок ниже,
  удаление или копирование справа. Пресет вместо типов показывает `.board-note` с замком.

### Строка обязательства — залежавшиеся
- `.tag.dot` на строке = ассистент предлагает закрыть карточку; tooltip объясняет, почему
  (словарь `CLOSE_HINT`, docs/ux-tasks.md §17.4). Такие строки собираются в последнюю
  секцию доски «Предлагаю закрыть» и получают лишнее hover-действие `refresh`
  («Оставить»). Новых классов не потребовалось — секции и hover-действия уже были.
- `.ac` / `.ac-drop` / `.ac-item` (+ `.ac-cur`, `.ac-name`, `.ac-addr`) — подсказка
  получателей под полем «Кому»/«Копия»: список — тот же `.ctx-menu`/`.ctx-item`, что у
  контекстного меню, обёртка лишь привязывает его к полю. Выбор — стрелки, Enter, Tab,
  мышь (`ui.js`); адреса даёт `/compose/recipients`.
- `.check-row` — строка-чекбокс в любой форме (подпись рядом с боксом, а не над ним,
  как у текстовых полей): композер, проекты, пространства, Настройки → Общие, мастер
  подключения модели («Отвечать без рассуждений»).
- `.att-chip` (+ `.missing`) — файл в композере: приложенный человеком и, при пересылке,
  вложение оригинала. `.missing` — файл, которого на этой стороне нет:
  жёлтый, семантикой `--warning`; с ним письмо не перешлётся.
- `.search-box` — поле поиска в шапке.
- `.proj-chip` / `.src-chip` (+ `.on`) — чипы-переключатели.
- `.chip-x` — крестик-действие внутри `.proj-chip` (снять привязку).
- `.sugg-row` — строка предложения в `.reason-box`: текст слева (может быть в две строки:
  факт + цитата с ссылкой), действия справа в одной `<form>` — кнопки не переносятся.

### Календарь
Как Календарь macOS (docs/feature-calendar.md §5.2). Шаблоны: `_calendar.html` — шапка и
выбор вида, `_calweek.html` — часы дня и недели, `_calmonth.html` — месяц, `_calmini.html` —
календарик перехода, `_calnav.html` — макрос `go(q)` для перехода с адресом в строке окна.
- `.cal` (+ `.cal-day` / `.cal-week` / `.cal-month` по виду) — весь календарь.
  `.cal-top` — липкая шапка: `.cal-bar` с `.cal-pick` (крупный `.cal-title`, по щелчку —
  `.cal-pop` с `.cal-mini`), по центру `.seg.cal-views` «День | Неделя | Месяц», справа
  `.cal-nav` «‹ Сегодня ›»; под ней `.cal-sources` — календари `.proj-chip` с
  `.cal-dot` (снятая галочка — пустой кружок); цвет — у каждого календаря внутри ящика
  («Мои события», «резерв»), не у ящика.
- Форма события (`_eventform.html`) — без своих классов: `.compose-form`, «весь день» и
  выбор рассылки — `.check-row`, дата и время в строку — `.period-row`, участники — `.ac`
  с `data-recipients`, как поле «Кому». Новое событие — щелчок или протяжка по `.cal-day`
  (`data-date`), кнопка «+» в `.cal-nav`.
- `.seg .btn.on` — нажатый сегмент: подложка `--accent-weak`, обводка `--accent`.
- День и неделя: `.cal-head` с `.cal-dayname` (сегодня — число в залитом кружке),
  `.cal-allday` с `.cal-chip`, `.cal-grid` — шкала `.cal-hour` (подпись стоит на линии
  часа) и `.cal-day` (`.weekend` затенён; часовые и бледные получасовые линии фоном).
  Ширины столбцов — `--cal-days` с сервера, положение блока — `--top/--h/--left/--w`,
  цвет календаря — `--ev/--ev-bg`: всё считает `calendar_grid`, CSS только ставит.
- `.cal-ev` — блок, содержимое в `.cal-ev-body`: время начала, под ним тема (переносится,
  строк — `--lines` от `calendar_grid`, последняя с многоточием) и место; `.short` — время и
  тема в строку. Блок уже 96px (встречи внахлёст) — только тема, строк `--lines-alone`: время
  видно по сетке. `.past` — приглушён; `.cancelled` — зачёркнут; `.sel` — открыт в панели.
  `.cal-now` — линия «сейчас», `.cal-now-label` — её время на шкале.
- Месяц: `.cal-mhead` (дни недели), `.cal-mweek` из `.cal-mday` (`.out` — не этот
  месяц, `.today`, `.weekend`): `.cal-mnum` открывает день, `.cal-mline` — встреча
  (`.cal-dot`, `.cal-mtime`, `.cal-mtitle`), `.cal-more` — «ещё N».
- На экране календаря **пустая панель чтения прячется** вместе с разделителем
  (`.app:has(#list .cal):has(#pane > .pane-empty)`): сетке нужна ширина. Поэтому ответ
  «не найдено» в панели события — не `.pane-empty`, иначе он исчез бы вместе с панелью.
- Панель события (`templates/_eventpane.html`): `.ev-line` — место с иконкой `pin`,
  `.ev-link` — ссылка на звонок, `.ev-cancelled` — зачёркнутый заголовок, `.ev-close` —
  крестик справа в заголовке (`closeEvent()` в ui.js).
- Клавиши (ui.js, `data-cal-key`): ← → — назад и вперёд, T — сегодня, 1 2 3 — вид, Esc —
  закрыть событие или календарик.

### Навигация
- `.sidebar` · `.nav` · `.nav-item` (+ `.active`) · `.nav-cap` · `.nav-sep` — сайдбар.
- `.space-switch` (+ `.space-switch-ic`) — переключатель пространства под брендом: форма с
  `<select>`, показывается при двух и более пространствах (docs/spaces.md §4).
- `.agent-status` (+ `.agent-dot.ok/.busy/.warn/.err`, `.agent-text`) — статус очереди
  ИИ-агента в подвале сайдбара над «Настройками» (`_agent_status.html`), сам себя
  опрашивает; кнопка `.act` «Разобрать заново» появляется только при ошибках или ждущих.
- `.settings-tabs` / `.tab` (+ `.active`/`.soon`) — табы настроек.

### Иконки
- **Стандарт — SVG через `{{ icon('name') }}`** (`email_reader/icons.py`), НЕ юникод-глифы
  (`⚙ ✓ ↩ →`). SVG рисуется в `1em`, наследует цвет через `currentColor` и
  масштабируется от `font-size` контейнера.
- Размер задаётся `font-size` элемента-обёртки (`--ic-sm`(16) `--ic-md`(18, базовый)
  `--ic-lg`(22)) — либо утилита-класс `.ic-sm/.ic-md/.ic-lg` прямо на вызове:
  `{{ icon('check', 'ic-md') }}`. Навигация (`.nav-ic`) рисует иконки в `--ic-md`.
  Глифы-символы визуально мельче кегля и рендерятся по-разному на ОС — не использовать.
- Доступные имена: `mail tag user gear database prompt lock bell appearance globe star
  paperclip pen check x reply forward inbox sent folder clock archive sun calendar mic
  handset dot flag refresh chevron trash more`. Нет нужного →
  добавь путь в `_ICONS` (`email_reader/icons.py`), стиль: линии, `viewBox 0 0 24 24`,
  `currentColor`, `stroke-width 1.7`.
- Мигрировано на `icon()`: сайдбар (`_sidebar.html`, `_counts.html`), кнопки действий
  (`_pane.html`, `_threadpane.html`), табы настроек, строки задач и их hover-действия
  (`_taskrow.html`), иконки типов (`TYPE_META`), статус очереди в подвале сайдбара.
  Остаток глифов — `＋` в заголовках сайдбара и `⚠`/`→` в баннере — точечно.

### Обратная связь
- `.toast` — транзиентное подтверждение (host `#toast-host`); с кнопкой `.toast-undo` —
  undo-тост после «Готово / Отложить / Не обязательство» (`showToast(msg, {action})`).
- `.htmx-indicator` — подпись «идёт…» рядом с кнопкой: невидима, пока htmx не пометил
  инициатора запроса (`hx-indicator`). Для действий, которые выглядят зависанием
  (сжатие базы, переиндексация).
- `.empty` / `.pane-empty` — пустые состояния.
- `.ctx-menu` / `.ctx-item` — контекстное меню. `.ctx-date` (+ `.ctx-date-input`) — тот же
  поповер с полем даты: «Выбрать дату…» показывает настоящее поле, календарь открывает
  сам браузер. Невидимого `input` + `showPicker()` здесь быть не должно: когда он молчит,
  не происходит ничего.
- `.palette-back` / `.palette` (+ `.palette-input`, `.palette-results`, `.palette-hint`) —
  палитра ⌘K: единственный вход в поиск по всему. Оверлей поверх приложения
  (`--scrim`, ширина `--palette-w`), своё поле ввода, внутри — те же `.srow`.
  Клавиши в `ui.js`; `kbd` — подпись клавиши.
- `.recip-wrap` + `.recip`/`.recip-more`/`.recip-rest` — строка получателей «Кому: a, b +N»
  с инлайн-раскрытием остатка по клику (нативный `<details>`, без JS). Макрос
  `recipients(label, addrs)` в `templates/_macros.html`.

## Как расширять

- **Новый статус-цвет** → пара `--x` / `--x-bg` в `:root` и в dark-блоке `tokens.css`.
- **Новый компонент** → сначала проверь инвентарь выше. Если правда новый —
  собери из токенов, добавь класс в `app.css` и строку в этот инвентарь.
- **Разовая верстка экрана** → комбинируй существующие классы, новый CSS не пиши.

Держи `styleguide.html` в актуальном состоянии: добавил компонент — добавь демо.
